# 🐱 Gatito Enojado (Angry Cat)

¡Bienvenido al repositorio oficial de **Gatito Enojado**! Un divertido juego arcade inspirado en los clásicos de los 80, desarrollado en dos versiones diferentes para explorar tanto el desarrollo de escritorio como el web.

---

## 📂 Estructura del Repositorio

- **`python-pygame/`**: Versión original desarrollada nativamente en Python utilizando la librería Pygame.
- **`web-js/`**: Versión moderna adaptada para la web utilizando JavaScript Vanilla (ES6 Modules) y HTML5 Canvas, con soporte para audio, animaciones y lógica de enemigos en tiempo real.

---

## 🚀 Tecnologías Utilizadas

- **Python & Pygame** (Lógica de bucle de juego, gestión de sprites y eventos de teclado).
- **JavaScript (ES6+), HTML5 Canvas & CSS3** (Manipulación del DOM, renderizado 2D y APIs de audio).
- **Git & GitHub** (Control de versiones y despliegue).

---

## 🎮 Características del Juego
- Movimiento fluido por laberintos con detección de colisiones por grilla.
- Enemigos inteligentes (ratones) con navegación libre por pasillos.
- Sistema de trampas con cuenta regresiva, explosiones en cadena y destrucción de bloques.
- Pantallas de pausa, victoria y Game Over, acompañadas de efectos de sonido y música de fondo.
